One default browser. Every profile.

If you use Chrome, Brave, Edge or Vivaldi, you have more than one profile: work and personal, a client's account, a test account. Profile Picker makes the choice once and then gets out of the way.

Rules that match how you work

Match the app a link was clicked in, the host, or the whole URL, with * wildcards and comma-separated alternatives. Rules are checked top to bottom and the first match wins.

Real browser profiles

Chrome, Brave, Edge, Vivaldi and Chromium profiles, with the names and colours from the browser itself. Open a link in the right profile, not the one that happened to be used last.

A picker, only when you want it

The panel appears next to the pointer, takes no focus from the app you were using, and closes with Esc. Choose with 1–9, the arrow keys or a click; ⌘C copies the link.

Always for this site

A one-off choice becomes a rule: “Always for github.com”, “Always for links from Slack”, or both at once. Hold ⌥ when clicking a link to force the picker every time.

Private by design

No account, no analytics, no network requests. Your rules live in a JSON file inside the app's container on your Mac. Links are logged only with the address redacted.

Out of the way

A menu bar app with no Dock icon. Hide the menu bar item if you want a completely invisible helper. Open at login only makes the first link a little faster.

Three steps, then forget it

  1. Make it your default browser

    Settings → General → Make Default Browser. macOS asks once; after that every link comes through Profile Picker.

  2. Add a rule, or just click

    Write rules in Settings → Rules, or let the picker create one with “Always for this site”. The built-in tester shows where a link will open.

  3. Arrive in the right profile

    Links open straight in the profile you chose, or the picker appears next to the pointer. No dock icon, no window, no waiting.

Open the DMG and drag Profile Picker to Applications. The app is signed with a Developer ID certificate and notarized by Apple.

This direct-download build runs outside the App Sandbox, so browser profiles work without a helper script. The Mac App Store version is sandboxed and uses an optional helper for profile selection instead.
