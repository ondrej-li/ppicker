Privacy Policy

Effective 20 November 2026

Profile Picker is a macOS app that opens links in the browser and browser profile you choose. It is designed to work without an account and without sending anything anywhere.

What Profile Picker collects

Nothing. Profile Picker does not collect, transmit, sell or share any personal data.

  • No analytics, telemetry, advertising or crash-reporting SDKs.
  • No network connections are made by the app.
  • No account, sign-in, email address or device identifier is requested.

What is stored on your Mac

  • Your settings and rules are stored in ~/Library/Containers/cz.ondralinek.ppicker/Data/Library/Application Support/config.json, inside the app's container. They never leave your Mac and are removed when you delete the app.
  • Links are written to the macOS system log with their address redacted, so you can diagnose routing if you choose to. macOS keeps and rotates that log; Profile Picker does not send it anywhere.
  • Browser profiles are read so the picker can show them. In the direct-download build the app reads the browser's Local State file itself. The App Store build uses the optional helper described below.

The optional helper (App Store build)

The helper is a short shell script that ships inside the app and is also published in the open-source repository. You install it yourself from Profile Picker's settings, into Profile Picker's own Application Scripts folder. It has two commands: copy the browser's list of profile names, and ask the browser to open a link with a given profile. The script does not access the network and does not read or write anything else. Deleting it is always safe.

Children

Profile Picker does not collect data from anyone, including children.
