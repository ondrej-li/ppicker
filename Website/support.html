Support

Profile Picker 1.0.0 · macOS 26 or later

Most questions are answered by the first two sections below. If not, the issue tracker is the quickest way to reach us.

Make Profile Picker the default browser

  1. Open Profile Picker from Applications. The settings window appears.
  2. Go to General and click Make Default Browser.
  3. Confirm the macOS prompt. The status should turn green.

You can also set it in System Settings → Desktop & Dock → Default web browser. The app lives in the menu bar; clicking a link is enough to wake it.

Browser profiles

A profile is missing from the picker

  • Make sure the browser is installed and the profile exists in it. Open the browser once after creating a profile.
  • In Profile Picker, open Settings → Browsers and click the refresh button.
  • Check that the profile's switch is on. Hidden profiles do not appear in the picker or in the rule editor.
  • In the App Store build, profile support needs the optional helper: Settings → Browsers → Install Helper…. The direct-download build reads profiles itself and needs nothing extra.

Which browsers support profiles?

Chrome, Brave, Edge, Vivaldi and Chromium. Safari, Firefox and other browsers work as a whole browser, without profiles.

Rules and the picker

How do I create a rule?

Open Settings → Rules and click +. A rule has conditions (the app a link was clicked in, the host, or the whole URL) and an action (the picker or a browser/profile). Rules are checked from top to bottom; the first match wins. The Test a link box shows where a link would go.

The quickest way is in the picker itself: choose a target, then pick Always for this site or Always for links from this app.

The picker does not appear

  • Check Settings → General → When no rule matches. If it opens a browser, the picker only appears when no rule matches.
  • A rule may be catching the link. Use the Test a link box to see which one.
  • Hold ⌥ Option while clicking a link to force the picker.
  • Make sure Profile Picker is the default browser; if another browser opens links, macOS is not sending them to Profile Picker.

A link opened without the profile I chose

If the browser cannot be launched with a profile, Profile Picker falls back to opening the link in that browser without a profile, so the link is not lost. In the App Store build this happens when the helper is not installed; in the direct build, check that the browser is installed and can be opened normally.

Data and privacy

Where are my rules stored?

In ~/Library/Containers/cz.ondralinek.ppicker/Data/Library/Application Support/config.json. There is no account and no cloud copy. Deleting the app removes the container and the rules.

Read the privacy policy for the full details.
